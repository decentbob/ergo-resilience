# Ergo: Notes on Resilience

A companion to the [Ergo Manifesto](https://ergoplatform.org/en/blog/2021-04-26-the-ergo-manifesto/), written by a community member. The manifesto tells us what Ergo is for and what it should be. This is an attempt at analysing what actually keeps Ergo decentralized and alive over the long run.

It is a starting point for discussion. If a section is wrong, dated, or badly framed, tell me. Feedback welcome: open an issue here, or discuss at [link].
